प्रत्ययाः (Grammatical Suffixes)

धातोः प्रातिपदिकात् च अनन्तरं यः वर्ण-समुदायः प्रयुज्यते सः प्रत्ययः भवति।

  • • क्त्वा: पूर्व-कार्यवाचके (e.g., पठ् + क्त्वा = पठित्वा)
  • • ल्यप्: यदा धातुः उपसर्गेण युक्तः भवति (e.g., सम् + पूज् + ल्यप् = सम्पूज्य)
  • • तुमुन्: निमित्तार्थक-क्रियापदे (e.g., खाद् + तुमुन् = खादितुम्)
  • • क्तवतु: भूतकालार्थे प्रयोगः (e.g., हस् + क्तवतु = हसितवान्)

कारक-विभक्तिः (6 Cases)

"कर्ता कर्म च करणं सम्प्रदानं तथैव च। अपादानाधिकरणे इत्याहुः कारकाणि षट्॥"

१. कर्ता (प्रथमा)रामः गच्छति।
२. कर्म (द्वितीया)रामः वनं गच्छति।
३. करणम् (तृतीया)पुष्पकविमानेन गच्छति।
४. सम्प्रदानम् (चतुर्थी)शिष्याय ज्ञानं ददाति।
५. अपादानम् (पञ्चमी)वृक्षात् पत्रं पतति।
६. अधिकरणम् (सप्तमी)छात्राः विद्यालये पठन्ति।

मनः पूतं समाचरत्

प्र०: लोकः कस्य आचरणम् अनुकरोति?
उ०: श्रेष्ठजनस्य।

प्र०: कीदृशी वाणी वक्तव्या?
उ०: मधुरा, (प्रिया), सत्या च।

प्र०: लक्ष्मीः कम् उपैति?
उ०: उद्योगिनं पुरुषसिंहम्।
